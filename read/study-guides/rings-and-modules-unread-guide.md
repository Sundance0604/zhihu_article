## 未学部分：哪些值得投入，哪些可以暂缓

对你“建立可迁移的结构性理解”的目标，最值得投入的是两条线：**同态 → 核 → 商 → 同构**，以及 **环作为算子 → 模 → 自由生成 → 正合与同调**。它们会在不同代数结构、线性代数和几何中反复出现。仅为重复检验公理而进行的计算，以及依赖后章先修的前瞻，不需要投入同等时间。

- **A — 必须掌握**：后续构造需要直接调用，或迁移价值很高。要能举例、给反例、独立使用；商的良定义、自由延拓等关键构造须能闭卷重建。
- **B — 理解证明**：结论和条件仍然重要，但证明套路已学过，或现在只需理解构造。能解释核心一步后即可前进，不要求长期背诵完整证明。
- **C — 本轮仅了解**：保留名称、用途和回查位置，完整证明可暂不读。这里的“可以暂缓”是相对你当前进度而言；进入相关后章时再升级。

**重要结论不等于每个证明细节都重要。** 例如第一同构定理的应用是 A，群论证明在环和模中的重复核验可快速通过；同调的定义和简单计算是 A，整条蛇引理的逐点追图证明先 C。一节没有 C 项时，也不必人为找出一部分跳过。

## 开始前：先用四个问题接通已学内容

1. 对群同态，为什么 $G/\ker f\cong\operatorname{im}f$？闭卷写出中间映射，分别检验良定义、单射和满射。
2. 给定交换环 $R$ 及 $a\in R$，为什么 $\operatorname{ev}_a:R[x]\to R$ 是环同态？一般非交换目标中还要检查什么交换条件？
3. $\operatorname{End}_{\mathbf{Ab}}(M)$ 的加法与乘法分别是什么？为什么复合对逐点加法左右分配？
4. 令 $\lambda_r(a)=ra$，验证 $\lambda_{rs}=\lambda_r\circ\lambda_s$；这个事实怎样把“乘法”转成“算子的复合”？

第 1、2 题若卡住，先回地图 II 7.4、8.1 与 III 2.2；第 3、4 题若卡住，先回 III 2.5。每次只修补卡点，不重读整章。先尝试 5–10 分钟，再看原笔记或下文提示。

## §3. Ideals and quotient rings

<a id="iii-3-1"></a>

### 3.1. Ideals（p.138）

**分级与理由**

- **A：理想的吸收条件、kernel 是理想**（Definition 3.1、Example 3.3）。它们决定哪些加法商能够保留环乘法，是后续商构造的入口；必须会判断例子，并独立证明核的双边吸收。
- **B：理想与子环的边界、理想逆像**（Remark 3.2、Exercise 3.2）。这些帮助检查条件，证明可复用“送过同态再检查”的套路；会讲清一步推理即可，不必另写长证明。本小节没有单列 C 项。

**问题意识**：加法子群足以让加法在商上成立；要让乘法也成立，子群还必须对整个环的左右乘法稳定。这个额外要求就是双边理想，不是“理想自身乘法封闭”那么弱。

**怎么读**：精读 Definition 3.1 和 Example 3.3；把“加法子群 + 双边吸收”写在一行。Remark 3.2 只需理解：本书子环含 $1_R$，真理想不能含 $1_R$，所以理想一般不是子环。先用交换环例子建立直觉，再检查左/右之别。

**主动任务**：比较 $2\mathbb Z\subset\mathbb Z$ 与 $\mathbb Z\subset\mathbb Q$；哪个是理想，哪个是本书意义的子环？独立证明环同态的核是双边理想。可选原书 Exercise III.3.2（p.143），练习理想逆像。

**卡住时的提示**：吸收条件允许乘的元素来自整个大环；用 $1/2$ 检验 $\mathbb Z\subset\mathbb Q$。核的证明直接计算 $f(ra)$ 与 $f(ar)$。

**过关**：能举“子环非理想”和“理想非子环”各一例，并解释原因。非交换环中的一般双边生成理想公式暂不展开。

<a id="iii-3-2"></a>

### 3.2. Quotients（p.139）

**分级与理由**

- **A：商环乘法的良定义与泛性质**（Definition 3.5、Theorem 3.8）。这是理想条件真正发挥作用之处，也是构造诱导同态的通用方法；比较代表元及唯一下降映射必须能闭卷重建。
- **A：characteristic**（Definition 3.7）。它把整数的像与环结构连接起来，后续域论频繁使用；会从核计算，并区分特征 0 与零环即可，不必现在扩展分类。
- **B：$\mathbb Q/\mathbb Z$ 的失败例**（Example 3.4）。一个反例足以说明“加法子群不够”；能复述矛盾就达到目的，无需堆叠同类反例。本小节没有单列 C 项。

**问题意识**：商不是删掉某些元素，而是把相差理想元素的对象视为相同。投影若要保乘法，就强迫 $(a+I)(b+I)=ab+I$；真正需要证明的是它不依赖代表元。

**怎么读**：精读 p.140 的良定义论证、Definition 3.5 与 Theorem 3.8。闭卷补出等式 $a'b'-ab=a'(b'-b)+(a'-a)b$，逐项指出用到左吸收还是右吸收。环公理的继承不再逐行抄写；泛性质中的唯一映射由 $r+I\mapsto f(r)$ 强制。

Definition 3.7 的 characteristic 从唯一同态 $\mathbb Z\to R$ 的核读出：$\ker=n\mathbb Z$，取唯一非负整数 $n$。特征 0 表示核为零，不表示 $1_R=0$；零环的特征是 1。

**主动任务**：用 Example 3.4 验证 $\mathbb Q/\mathbb Z$ 的陪集乘法为什么失败；算 $\mathbb Z/6\mathbb Z$ 和 $\mathbb Q$ 的特征。再尝试证明非零整环的正特征一定是素数（Exercise III.3.14，p.144）。

**卡住时的提示**：$0+\mathbb Z=1+\mathbb Z$，让它们乘同一个陪集。特征的练习中，若最小正整数 $n=ab$ 合成，考虑 $(a1_R)(b1_R)$。

**过关**：能闭卷重建良定义与泛性质；不能把“所有加法商”都称为商环。

### 3.3. Canonical decomposition and consequences（p.141）

**分级与理由**

- **A：标准分解与第一同构定理的应用**（Theorem 3.9、Corollary 3.10）。识别一个新商环主要靠“构造同态、算核与像”，以后会反复调用；要能用于新例。
- **B：理想对应、第三同构定理及第二同构的类型说明**（Proposition 3.11 与本节备注）。核心方法已在群中学过，值得理解的是新增的环结构条件；能选出映射并读出核即可，不必完整重抄群论证明。本小节没有单列 C 项。

**问题意识**：用同态的 kernel 描述关系、用 image 描述实际得到的结构。结构层级变了，证明策略仍是“构造同态 → 算核与像 → 第一同构定理”。

**怎么读**：Theorem 3.9、Corollary 3.10 的群论骨架已学，只补映射保乘和保幺的检查。Proposition 3.11 读懂 $r+I\mapsto r+J$ 与其核即可；不要重写第二套完整证明。

**主动任务**：构造 $\mathbb Z[x]\to\mathbb F_2$，先代入 0 再模 2。证明它满射，且核是 $(2,x)$，据此识别 $\mathbb Z[x]/(2,x)$。这是自拟任务，也为 III 4.3 的 Example 4.10 做准备。

**卡住时的提示**：把多项式拆成常数项与 $x$ 的倍数；核的两个包含都要证明。对应定理比较的是理想的集合，不是声称元素投影单射。

**过关**：可以用一张小图与三句话完成新商环的识别。第二同构定理的理想版本先了解其结构类型，等到模中再系统使用：真理想按本书约定通常不是含幺环。

## §4. Ideals and quotients: Remarks and examples. Prime and maximal ideals

<a id="iii-4-1"></a>

### 4.1. Basic operations（p.144）

**分级与理由**

- **A：生成理想、和、交、积以及它们的区别**。这是表达关系和计算商的基本语言，也将迁移到子模；要会用有限和描述并计算简单例子，尤其不能误认交总等于积。
- **B：Noetherian、PID 与 $\mathbb Z$ 为 PID**（Definitions 4.2–4.3、Proposition 4.4）。定义和条件要读准，但系统理论在第 V 章；现在理解“有限生成/一个元生成”的区别，并看懂由整数子群分类得到的证明即可。本小节没有单列 C 项。

**问题意识**：用生成元指定理想，用和、交、积组合约束。以下简单生成元公式先限定在交换环；非交换环中的 $Ra$ 一般只是左理想。

**怎么读**：精读 $(a_1,\ldots,a_n)=\{\sum r_i a_i\}$，理解和是同时包含给定理想的最小理想。注意 $IJ$ 是有限和 $\sum a_i b_i$ 构成的理想，而不是只取单个乘积的集合；总有 $IJ\subseteq I\cap J$。Noetherian 与 PID 的定义读懂即可，第 V 章再深化证明。

**主动任务**：计算 $\mathbb Z$ 中 $(4)+(6)$、$(4)\cap(6)$、$(4)(6)$。完成后选 Exercise III.4.5（p.154）：若 $I+J=R$，证明 $IJ=I\cap J$。理解了这一步即可前进，不必现在深入全部理想运算习题。

**卡住时的提示**：写 $1=i+j$，让任意 $z\in I\cap J$ 乘它；分别识别两项。最大公因数控制和，最小公倍数控制交。

**过关**：不再默认交等于积；能区分“每个理想有限生成”和“每个理想主生成”。

<a id="iii-4-2"></a>

### 4.2. Quotients of polynomial rings（p.146）

**分级与理由**

- **A：首一多项式商的低次代表、乘法约化和加根例子**（Lemma 4.5、Proposition 4.6、Examples 4.7–4.8）。它们把抽象商变成可计算对象，直接服务域扩张与算子理论；必须会实际计算，并辨明加法群同构不自动是逐分量乘法的环同构。
- **B：长除法的存在性与余式唯一性的证明展开**。方法与已知除法相近，关键是首一允许消去最高项；理解这一步和次数反证即可，重复运算可略。本小节没有单列 C 项。

**问题意识**：$R[x]/(f)$ 是一个使 $f(\bar x)=0$ 的新环。首一多项式允许用余式把无限形式压成有限个坐标，而这些坐标的乘法由关系决定。

**怎么读**：重点是 Lemma 4.5、Proposition 4.6 与 Examples 4.7–4.8。对交换环 $R$ 和首一的 $d$ 次多项式，元素有唯一代表 $a_0+\cdots+a_{d-1}x^{d-1}$。Proposition 4.6 首先给出加法群同构 $R[x]/(f)\cong R^{\oplus d}$；它**不**宣称乘法是逐分量乘法。首一保证除法可做，不能对任意系数环的任意非首一多项式照搬。

**主动任务**：在 $\mathbb R[x]/(x^2+1)$ 中计算 $(1+\bar x)^2$；独立写一般两个一次代表元的乘积。在 $\mathbb F_2[x]/(x^2+x+1)$ 中列出四个元素，检验三个非零元素是否都有逆。后者是自拟基础构造，不要求此时学习有限域分类。

**卡住时的提示**：用 $\bar x^2=-1$ 或 $\bar x^2=\bar x+1$ 约化；在四元素例子直接检查 $\bar x(\bar x+1)$。不要将“加入一个根”误认为“任何这样的商都是域”。

**过关**：能做商中的乘法并说明 $\mathbb R[x]/(x^2+1)\cong\mathbb C$ 的来源；不必通读所有长除法重复计算。

### 4.3. Prime and maximal ideals（p.150）

**分级与理由**

- **A：prime/maximal 的商判据与等价条件**（Definition 4.9、Proposition 4.11）。这是从理想翻译到整环、域的核心接口；必须会判断例子、证明 maximal 蕴含 prime，并给出逆向反例。
- **B：有限商与 PID 中的特殊结论**（Propositions 4.12–4.13）。它们是已学结论的组合，理解有限性、PID 及非零条件各用在哪里即可；不用背两份独立证明。
- **C：Spec、Krull dimension 与 Nullstellensatz 前瞻**（Examples 4.14–4.15）。它们有长期几何价值，但当前完整理解成本高；只看动机和一个理想链例子，留到 VII §2 再深读。

**问题意识**：通过商观察理想。对交换含幺环的真理想 $I$，素性对应商为整环，极大性对应商为域。这是把局部的包含/整除条件变成整体结构性质。

**怎么读**：精读 Definition 4.9、Proposition 4.11；在商的表述与 $ab\in I\Rightarrow a\in I$ 或 $b\in I$ 之间双向翻译。极大性用理想对应定理理解。Propositions 4.12–4.13 抓有限性与非零理想条件，Spec、维数与 Nullstellensatz 的段落先只看动机。

**主动任务**：判断 $\mathbb Z$ 中 $(0)$、$(2)$、$(6)$ 的素性与极大性；用商环解释 $\mathbb Z[x]$ 中 $(x)$ 与 $(2,x)$ 的不同。证明 maximal $\Rightarrow$ prime，并给逆命题反例。

**卡住时的提示**：先计算商，避免在原环中反复展开定义；$(x)$ 的商还有哪些非单位？

**过关**：始终检查 $I\ne R$，知道 PID 的“非零素理想极大”不能删去“非零”。几何前瞻不作为继续读模论的门槛。

## §5. Modules over a ring

<a id="iii-5-1"></a>

### 5.1. Definition of (left-) R-module（p.156）

**分级与理由**

- **A：模公理与 $R\to\operatorname{End}_{\mathbf{Ab}}(M)$ 的等价描述**（Claim 5.1、Definition 5.2）。这是全章最有迁移价值的节点之一，把数乘、阿贝尔群和算子统一起来；必须能双向转换并构造非向量空间的模例。
- **B：左右模与 opposite ring**。它解决非交换时的次序问题；现在能解释为何反转乘法即可，先不展开一般非交换模的技术例子。本小节没有单列 C 概念。

**问题意识**：模是一个阿贝尔群 $M$，再给它一套相容的标量算子。结构映射 $\sigma:R\to\operatorname{End}_{\mathbf{Ab}}(M)$ 把环加法变为算子加法，把环乘法变为算子复合，且 $1_R$ 作用为恒等。

**怎么读**：精读 Claim 5.1 与 Definition 5.2；对照四条数乘公理，看每条对应环同态的哪项性质。不要默认“模就是有基的向量空间”：一般环中标量未必有逆，模也未必自由。左右模段落读懂复合次序即可。

**主动任务**：给 $\mathbb Z/6\mathbb Z$ 定义 $\mathbb Z$-作用，验证最关键的两条相容性；计算作用同态的核。说明为什么这里的作用不是忠实的。再解释它为什么不能以同一加法群成为 $\mathbb Q$-向量空间。

**卡住时的提示**：把整数乘法理解为反复加法；$\sigma(6)=0$ 不妨碍 $\sigma(1)=\operatorname{id}$。如果所有非零有理数可逆，其算子也必须可逆。

**过关**：能在“环到 End 的同态”与“满足四公理的数乘”之间来回转换，不把左正则表示的单射性推给任意模。

<a id="iii-5-2"></a>

### 5.2. The category R-Mod（p.158）

**分级与理由**

- **A：R-linear 映射、Ab 与 $\mathbb Z$-Mod 的对应、域上的模即向量空间**（Proposition 5.3、Examples 5.4–5.5）。这些让新定义立即接入已知结构；必须能判断同一个映射在不同标量环下是否线性。
- **B：R-algebra 与 Hom 的额外结构**（Example 5.6、Definition 5.7 及本节 Hom 段落）。它们会再次使用，但当前先理解“多了什么相容条件”，尤其中心与交换性；不要求此时系统研究所有代数例子。本小节没有单列 C 概念。

**问题意识**：模同态既保加法，也与标量作用交换。固定同一个标量环后，这些映射构成 R-Mod；不同的模结构不能只看底层加法群就忽略。

**怎么读**：Proposition 5.3 与 Examples 5.4–5.5 是重点：Ab 就是 $\mathbb Z$-Mod，向量空间就是域上的模。Definition 5.7 的 R-algebra 加入的是乘法结构；本书要求 $R$ 交换且标量像进入目标中心。Hom 的逐点加法始终给阿贝尔群，按目标数乘得到 R-module 结构则一般需要 $R$ 交换。

**主动任务**：证明 $\mathbb C\to\mathbb C$ 的共轭映射是 $\mathbb R$-linear，却不是 $\mathbb C$-linear。然后选 Exercise III.5.5（p.163），在交换环条件下解释 $\operatorname{Hom}_R(R,M)\cong M$。

**卡住时的提示**：测试标量 $i$；对 Hom 问题先看 $f(1)$，再用 $f(r)=rf(1)$。

**过关**：能识别对象、态射、零模，区分 ring、module、algebra；复杂 division algebra 例子暂缓。

<a id="iii-5-3"></a>

### 5.3. Submodules and quotients（p.160）

**分级与理由**

- **A：子模、商模及商泛性质**（Claim 5.11、Theorem 5.14）。核、余核、同调都依赖它；必须会验证数乘良定义并构造下降映射。
- **B：left ideal、kernel/image、$IM$ 的例子与验证**（Examples 5.8–5.13）。主要用于认清结构类型，证明多是已知群论检查再加数乘稳定；理解关键新增条件后即可前进。本小节没有单列 C 项。

**问题意识**：子模是对所有标量稳定的加法子群。商的数乘由投影的线性性强迫为 $r(m+N)=rm+N$；这次不再有群论的额外正规性障碍。

**怎么读**：精读 Claim 5.11 与 Theorem 5.14，复用已学商泛性质。重点辨别：$R$ 作左模时的子模是左理想；仅有左理想已足以作商左模，但商环需要双边理想。$IM$ 的定义是有限和 $\sum i_km_k$，不能只取单项乘积。

**主动任务**：把 $\mathbb Z/n\mathbb Z$ 同时看作商加法群、商环和 $\mathbb Z$-模，说明每种结构需要哪些条件。用 $f:M\to P$ 构造 $M/N\to P$，自己标出“$N\subseteq\ker f$”用在哪一步。

**卡住时的提示**：两个代表元差在 $N$ 中，数乘后差仍在 $N$ 中；其他群层面的验证已完成。

**过关**：不混同模的商与环的商，能独立说明下降映射的良定义。

### 5.4. Canonical decomposition and isomorphism theorems（p.162）

**分级与理由**

- **B：第二/第三同构定理、子模对应及重复的证明检查**（Propositions 5.17–5.18）。构造套路在群中已经出现；掌握同态和核，不必为模再背一整套证明。第一同构定理的群论骨架也可引用，只补线性性。本小节没有单列 C 项。

**问题意识**：同构定理是寻找新结构描述的工具，不是需要单独背三份的公式集。

**怎么读**：Theorem 5.15、Corollary 5.16 要会应用；Propositions 5.17–5.18 只需重建定义映射并检查线性性。群论里的正规性在模中自动，证明更直接。

## §6. Products, coproducts, etc., in R-Mod

<a id="iii-6-1"></a>

### 6.1. Products and coproducts（p.164）

**分级与理由**

- **A：积与直和的两个泛性质、无限情形的有限支撑**（Proposition 6.1、Exercise 6.7）。它们决定能否合法地组合映射，并直接构成自由模；必须能写两种方向的唯一映射。
- **B：逐分量的模公理验证**。这是 Grp/Ab 的重复模式，只需理解标量作用相容，不必反复展开结合律和分配律。pullback/pushout 习题暂不扩展，不作为本节核心验收。

**问题意识**：积统一“映到各分量”的信息；余积统一“从各分量映出”的信息。有限个模时二者由同一个直和对象承载；无限时必须区分。

**怎么读**：Proposition 6.1 的两类泛性质都要会写。结合 Exercise III.6.7（p.172）认识一般族：积允许任意坐标，直和只允许有限支撑；否则从直和映出时所需的求和可能没有定义。

**主动任务**：对映射 $f_i:M_i\to P$，写从 $\bigoplus M_i$ 到 $P$ 的公式；对 $g_i:P\to M_i$，写到 $\prod M_i$ 的公式。说明 $(1,1,\ldots)$ 为什么能区分 $\mathbb Z^{\mathbb N}$ 与 $\mathbb Z^{\oplus\mathbb N}$ 的底层定义。

**卡住时的提示**：注意这只是显示两集合不同；要证明两个模不抽象同构，原书 Exercise 6.7 进一步提示比较基数。无需为了本节先学习拓扑中的无限级数。

**过关**：能说明映射方向与有限支撑的必要性。pullback/pushout 习题本轮可留作索引。

<a id="iii-6-2"></a>

### 6.2. Kernels and cokernels（p.166）

**分级与理由**

- **A：kernel/cokernel 的构造与泛性质、mono/epi 判据**（Proposition 6.2）。它们是下一节正合与同调的直接前置；必须会计算并区分“单满射”与“有单侧逆”。
- **C：additive/abelian category 的一般定义**。先掌握 R-Mod 中具体发生的事情已足够继续；抽象公理留到 IX §1，此时不需先攻克一般范畴理论。本小节没有另列 B 项。

**问题意识**：kernel 测量输入端被压掉的信息，cokernel 测量目标端未被像填满的信息。它们是带映射的泛性质对象，并非仅是两个集合。

**怎么读**：精读 Proposition 6.2 的结构与范畴差异。给 $f:M\to N$，有 $\operatorname{coker}f=N/\operatorname{im}f$；在 R-Mod，mono 等价单射，epi 等价满射。但单射不自动有线性左逆，满射也不自动有线性右逆。

**主动任务**：计算 $\mathbb Z\xrightarrow{\times2}\mathbb Z$ 的 kernel/cokernel，并证明没有 $\mathbb Z$-linear 左逆；检查 $\mathbb Z\to\mathbb Z/2\mathbb Z$ 为什么没有线性右逆。把这些与 Ring 中的 $\mathbb Z\hookrightarrow\mathbb Q$ 比较。

**卡住时的提示**：任何 $\mathbb Z\to\mathbb Z$ 的群同态由 1 的像决定；来自 $\mathbb Z/2\mathbb Z$ 的像则必须满足二倍为零。

**过关**：明确“单/满”“有单侧逆”“同构”三者关系。additive/abelian category 的抽象公理先列 C。

<a id="iii-6-3"></a>

### 6.3. Free modules and free algebras（p.167）

**分级与理由**

- **A：自由模 $R^{\oplus A}$ 及其唯一线性延拓**（Claim 6.3）。它是生成、表示、矩阵描述的共同起点；必须能从生成元的像构造同态，并解释有限支撑的必要性。
- **B：自由交换 R-algebra**（Proposition 6.4）。重点是与自由模的区别；证明就是多项式泛性质的再次应用，理解构造即可，不重复精读。
- **C：非交换自由代数的一般字构造**。当前模论主线不依赖其细节；记住允许不交换的变量，留到 VIII 4.4 再与 tensor algebra 对照。

**问题意识**：自由模允许有限线性组合；自由交换代数还允许相乘，故是多项式环。自由对象依赖范畴，不能只凭“由几个生成元生成”混为同一结构。

**怎么读**：精读 Claim 6.3：$F_R(A)\cong R^{\oplus A}$，任意 $a\mapsto m_a$ 唯一延拓为 $\sum r_a a\mapsto\sum r_a m_a$。Proposition 6.4 是多项式泛性质的复现，读骨架即可；非交换自由代数的字构造先 C。

**主动任务**：完成 Exercise III.6.1（p.172），特别解释有限支撑和唯一性。再用 $\mathbb Z/2\mathbb Z$ 说明“有限生成”不等于“自由”；比较自由模 $R^{\oplus2}$ 与自由交换代数 $R[x,y]$ 中生成元能产生什么。

**卡住时的提示**：自由 $\mathbb Z$-模中的非零元素不可能被非零整数杀掉；模生成只允许线性组合，代数生成允许任意有限多项式。

**过关**：会使用自由模的 UP；不要求在此证明一般环上自由模秩的理论。

<a id="iii-6-4"></a>

### 6.4. Submodule generated by a subset; Noetherian modules（p.169）

**分级与理由**

- **A：生成子模、有限生成及自由模满射描述**。这是后续表示和分类使用的语言；必须区分有限生成、自由与底层集合有限。
- **B：Noetherian 的定义与子模/商模闭包性质**（Definition 6.6、Proposition 6.7、Corollary 6.8）。要理解它控制“每个子模”，以及证明如何提升生成元；完整理论会在第 V 章继续，不需现在扩展所有等价条件。
- **C：无限变量环中非有限生成理想的完整论证**（Example 6.5）。先用它记住错误推广会失败即可；会查一个反例比此时深究全部技术更划算。

**问题意识**：有限生成只控制整个模的描述；Noetherian 控制它的每个子模，因而更稳定。

**怎么读**：生成子模就是自由模到 $M$ 的自然映射的像；有限生成等价于存在 $R^{\oplus n}\twoheadrightarrow M$。Definition 6.6 读准“每个子模”；Proposition 6.7 追“交 + 商 + 提升生成元”即可，Corollary 6.8 看懂如何由 $R^{\oplus n}$ 传给商。例子 6.5 用于否定不加条件的推广，暂不深挖。

**主动任务**：闭卷解释为什么 $R$ 自身只由 1 生成，却仍可能不是 Noetherian。假定 $R$ 为 Noetherian，画出有限生成模及其子模为什么都有限生成的推理链。

**卡住时的提示**：对 $P\le M$ 用 $P\cap N$ 与 $P/(P\cap N)\cong(P+N)/N$；从商中提升生成元，再加交的生成元。

**过关**：没有把“有限生成”误当成“所有子模都有限生成”；ACC 等价表述留到 V 1.1。

<a id="iii-6-5"></a>

### 6.5. Finitely generated vs. finite type（p.171）

**分级与理由**

- **A：作为模有限生成与作为代数有限生成的区别**（Example 6.9 及前文）。这不是术语细节：前者只允许线性组合，后者允许多项式；混淆会影响后续域扩张和代数几何。必须会用 $R[x]$ 解释逆向为什么失败。
- **C：Nullstellensatz、Hilbert basis theorem 的证明前瞻**。这里只建立用途索引，所需工具和证明将出现在 VII 2.2、V 1.1；不应因著名而在此停下来补完整理论。本小节没有另列 B 项。

**问题意识**：同一代数 $S$ 可以作为模或作为代数谈生成。前者只准线性组合，后者准任意多项式，允许的表达式差很多。

**怎么读**：对照 $R^{\oplus n}\twoheadrightarrow S$ 与 $R[x_1,\ldots,x_n]\twoheadrightarrow S$；保留“finite $\Rightarrow$ finite type”的方向与逆向反例。Example 6.9 精读，Nullstellensatz、Hilbert basis theorem 的预告只记索引。

**主动任务**：对非零交换环 $R$ 说明 $R[x]$ 作为 R-algebra 由 $x$ 生成，却不是有限生成 R-module。再说明首一 $f$ 的 $R[x]/(f)$ 为什么是有限 R-module，即使它的底层集合可能无限。

**卡住时的提示**：有限多个多项式的次数有共同上界，R-linear 组合不能突破它；商中的首一关系则恰好让高次项约化。

**过关**：每次说“有限生成”都会补明“作为哪个环上的模/代数”。

## §7. Complexes and homology

<a id="iii-7-1"></a>

### 7.1. Complexes and exact sequences（p.174）

**分级与理由**

- **A：complex、exact 与 short exact sequence**（Definition 7.3 及前文）。它们是描述映射之间结构关系的通用语言；必须能区分包含与相等，并逐位置检验正合。
- **B：端点单满射的解释与长正合序列的拆分图**（Examples 7.1–7.2 及后文）。理解零对象如何强迫核像条件即可；不需要背整张大图。本小节没有单列 C 项。

**问题意识**：复形只要求“上一步的像被下一步杀掉”，正合要求“被下一步杀掉的全都来自上一步”。前者是包含，后者是相等。

**怎么读**：精读 $d_id_{i+1}=0$、$\operatorname{im}d_{i+1}=\ker d_i$ 及 Definition 7.3。短正合序列 $0\to L\xrightarrow{a}M\xrightarrow{b}N\to0$ 同时编码单射、满射与中间的核像相等；把 $L$ 经 $a$ 识别为子模后，$N\cong M/L$。

**主动任务**：逐位置验证 $0\to\mathbb Z\xrightarrow{\times2}\mathbb Z\to\mathbb Z/2\mathbb Z\to0$ 正合。另检验 $\mathbb Z\xrightarrow{\times2}\mathbb Z\xrightarrow{0}\mathbb Z$：它是复形吗？在中间正合吗？

**卡住时的提示**：写出中间那个零映射的核与前一个映射的像，别仅凭复合为零就下结论。

**过关**：能逐点而非整体含糊地说“在哪里正合”；无需背 p.176 的大拆分图。

<a id="iii-7-2"></a>

### 7.2. Split exact sequences（p.177）

**分级与理由**

- **A：分裂的含义与不分裂的标准反例**（Example 7.4 及前文）。它防止把所有“子模 + 商”误认为直和，对理解扩张非常重要；要能独立否定整数序列分裂。
- **B：单侧逆与分裂等价的构造证明**（Proposition 7.5）。构造本身有价值，读懂截面/投影如何拆出直和即可；初轮不要求记住全部互逆映射核验。本小节没有单列 C 项。

**问题意识**：短正合给出子模和商的关系；分裂还要求它与标准直和序列相容地同构。不是只看中间模能否碰巧抽象同构。

**怎么读**：先比较标准直和序列与 Example 7.4 的非分裂例。Proposition 7.5 读懂单侧逆的作用。若有截面 $s:N\to M$ 满足 $bs=1_N$，可用 $(l,n)\mapsto a(l)+s(n)$ 得到 $L\oplus N\to M$。

**主动任务**：证明上一小节的整数短正合序列不分裂。再选 Exercise III.7.6（p.183），理解有右逆时的直和构造，而不是背结论。

**卡住时的提示**：若 $s:\mathbb Z/2\mathbb Z\to\mathbb Z$ 存在，它的每个像必须被 2 杀掉；与 $bs=1$ 是否相容？

**过关**：能解释“epi 不自动 split epi”，并给出一例。证明中的互逆映射核验看懂即可。

<a id="iii-7-3"></a>

### 7.3. Homology and the snake lemma（p.178）

**分级与理由**

- **A：同调的定义、商的合法性、零同调与正合、两项复形的计算**（Definition 7.6、Example 7.7）。这是以后进入拓扑、几何时能反复使用的核心；先掌握一个可计算模型，价值高于背长序列。
- **B：蛇引理的陈述、连接同态及选择独立性**（Lemma 7.8）。真正值得学习的新方法是“选一个提升，再证明结果不依赖选择”；能讲出这条构造路线即可。
- **C：蛇序列每个位置的正合验证、一般长正合同调序列的推广**。它们需要较多追图练习，当前并非理解同调定义的前提；先跳过完整证明，实际使用蛇引理或进入 IX 章时再升级。

**问题意识**：$H_i(M_\bullet)=\ker d_i/\operatorname{im}d_{i+1}$ 测量正合性的缺口。商合法是因为复形条件确保分母包含在分子中；它不是两个对象的数值相减。

**怎么读**：Definition 7.6、Example 7.7 列 A；先会算 $0\to M_1\xrightarrow f M_0\to0$ 的两个同调，分别是 kernel 与 cokernel。蛇引理 Lemma 7.8 的陈述和连接同态构造列 B；第一次只追 p.180–182 的关键路线。整条序列逐点正合验证与任意复形的推广先 C，实际需要时再升级。

**主动任务 1**：计算两项复形 $0\to\mathbb Z\xrightarrow{\times2}\mathbb Z\to0$ 的 $H_1,H_0$，解释它为何不在两个位置都正合。再将 $\times2$ 换成恒等映射比较。

**主动任务 2**：照原书 p.179 的两行短正合图，从 $a\in\ker\nu$ 出发，口述 $\delta:\ker\nu\to\operatorname{coker}\lambda$：

1. 沿 $\beta_1$ 将 $a$ 提升到 $c\in M_1$。
2. 经 $\mu$ 下移到 $M_0$；交换性说明它落在 $\ker\beta_0$。
3. 下行正合使它来自 $\alpha_0(e)$；单射性保证这个 $e\in L_0$ 唯一。
4. 将 $e$ 取到 $L_0/\operatorname{im}\lambda$ 中。

**卡住时的提示**：如果换了第 1 步的提升，两个提升之差位于 $\ker\beta_1=\operatorname{im}\alpha_1$；追这个差在下行造成的变化，看看为何取商后消失。这是“选择不唯一，但结果仍良定义”的又一次出现。

**过关**：同调计算能独立完成，连接同态能复述构造与选择独立性的原因。不必在本轮背全部蛇引理证明；若继续学 IX 章，应把完整追图练习从 C 升到 B/A，而非永久略过。
