## 先按你的真实背景调整路线

你明确说明：**物理只在高中系统学过；数学学过实分析、部分泛函分析、数值代数、数值分析、凸优化，也学过微积分、线代、常微分方程并能做基础计算。** 这表示数学侧不必从基础重学，物理侧却不能因为能读懂符号就视为具备大学量子力学、统计物理、相对论或场论先修。

本轮选择 **几何与拓扑为主线、物理概念小步补充**，而不是把第1章全部技术先修完。原书 How to Read this Book（p.xxi）明确列出数学路线从第2章起；几何拓扑单学期路线为第2–7章，第8章可选。作者的物理综述默认的背景比高中物理高，不应把你卡在第1章。

**A/B/C 表示重要性，阅读安排表示当前投入，二者分开。** 你熟悉的向量空间仍是 A，但通过一个诊断题就可以略读；新的张量、商拓扑、切/余切与微分形式也是 A，可能值得精读。大量 QFT 技术因当前先修不足暂列 C，未来若转入该方向再升级。

## 阅读原书时的数学校对提醒

你的数学背景足够辨认一些简化或笔误，不必因与已学分析冲突而反复怀疑自己。以下相关页已查看图像；只修正学习指导中的使用方式，不改原书或笔记。

- **p.77：补空间不自动是正交补。** 秩零度证明中任意提升像的基得到一个直和补；必须先给内积并作适当选择，才能把它称为正交补。该页的代数配对也不应直接等同已经指定的正定内积。
- **p.81：一般度量空间并不都是流形。** 例如带通常距离的有理数空间不是局部欧氏空间。不要照该页引言建立“度量空间必属流形”的包含链。
- **p.83：一般边界应为闭包减内部**，$\partial A=\overline A\setminus A^\circ$。该页印刷式少了闭包，取开区间即可发现与随后例子不一致。
- **p.85：连通的分割需两个非空不交开集；单连通还须道路连通。** 连通与道路连通在一般拓扑空间不能等同；进入流形后有更好的局部性质。
- **p.88：同伦等价不能只要求来回映射存在。** 还须 $gf\simeq\operatorname{id}_X$、$fg\simeq\operatorname{id}_Y$；本节是例子导入，正式内容到第4章补齐。

这些提醒是精读时的条件检查，不意味着你需要为所有旁支先另读一本一般拓扑教材。

| 商集合 ↔ 商拓扑 | Algebra 的商经验可用，拓扑结构须另检查 | 解释半开区间选代表与圆的拓扑不同 |
| 对偶/算子 ↔ 余切/张量 | 数值代数的坐标表述需转为基无关语言 | 从定义构造对偶拉回、说明一般映射不需可逆 |
| 核/像/商 ↔ 同调 | 两本书在这里真正汇合 | 对单个三角形验证边界的边界为零 |
| 拓扑等价 ↔ 同胚/同伦/不变量 | 相似图形不是严格的分类依据 | 解释同伦等价不同胚的例子和不变量的单向逻辑 |
| 微分运算 ↔ 形式/Stokes/整体障碍 | 把熟悉分析转到流形上 | 算一次形式拉回、外微分，说明闭不总正合 |
| 局部模型 ↔ 拼接/连接/曲率 | 是结构性理解的长期主干 | 用一个覆盖和交叠变换解释整体并非全局积 |
