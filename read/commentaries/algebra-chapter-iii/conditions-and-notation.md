# 条件与符号提醒

[返回目录](README.md)。这里集中保存正文里容易遗漏的前提，不另写习题。

| 位置 | 条件或区别 | 少掉以后哪里会出问题 |
|---|---|---|
| III 4.1 | 左理想、右理想、双边理想不同 | $Ra$ 在非交换环里不自动是双边理想 |
| III 4.1 | 无限生成只允许单个表达式有限支撑 | 普通环没有默认的无穷求和 |
| III 4.2 | 首一可在一般系数环上作长除法 | 非单位首项系数可能不能消去 |
| III 4.2 | 余式对应先是加法群同构 | $R^d$ 原有的逐项乘法一般不是商乘法 |
| III 4.2 | 正次数、非零环是加根嵌入的常见情形 | 常数首一多项式 1 的商是零环，不属于“保留系数环再加根”的非退化情况 |
| III 4.3 | 交换环且理想真 | 零商不符合本书整环、域的非零要求 |
| III 4.3 | 有限商时才用有限整环为域 | 无限整环可以不是域 |
| III 4.3 | PID 中素理想还要求非零 | 消去生成元那一步不能用零；$(0)\subset\mathbb Z$ 是反例 |
| III 4.3 | 链长数严格包含次数，维数取上确界 | 写一条链只给下界，不证明没有更长链 |
| III 5.1 | 固定左作用次序 | $(rs)m=r(sm)$ 中的操作顺序不是可任意交换的 |
| III 5.2 | 代数的系数像进中心 | 标量穿过内部乘积的步骤需要它 |
| III 5.2 | Hom 一般先是阿贝尔群 | 逐点乘任意非中心标量未必仍是线性映射 |
| III 5.3 | 子模稳定与双边理想条件不同 | 左理想商可作左模，却未必能作环 |
| III 5.4 | 子模对应只取包含被除子模的对象 | 逆像才能恢复原对象，而非额外加上被除部分 |
| III 6.1 | 有限积与余积重合，不能直接推广无限 | 无限积允许任意支撑，余积只允许有限支撑 |
| III 6.2 | mono/epi 在 R-Mod 中等价于单/满射 | 不能无条件推广到 Ring 等其他范畴 |
| III 6.2 / 7.2 | 集合逆向选择与线性逆向选择不同 | 挑代表元可能不保加法、标量 |
| III 6.3 | 自由对象的 $j$ 单射须注意零环 | 零环只有零模，任意多标签仍只能映到同一个零 |
| III 6.4 | 有限生成不保证子模有限生成 | 需要 Noetherian 控制，或底环 Noetherian 的相应结论 |
| III 6.5 | finite 是有限模生成，不是有限集合 | $\mathbb Z$ 自身是例子 |
| III 6.5 | 生成时是否允许相乘、求逆不同 | $R[x]$、$k(t)$ 的生成性质因此不同 |
| III 7.1 | 复合为零仅保证像含于核 | 正合要求等式 |
| III 7.2 | 分裂同构必须与箭头相容 | 只写一个对象同构没有完整交代序列数据 |
| III 7.3 | 连接映射要模掉原像选择造成的差别 | 左下元素 $e$ 一般不唯一，只有其余核类独立 |

以上提醒是解释范围与假设，不把它们统称为原书排印错误。对本注采用的零环边界、维数上确界等说明，正文明确补出了更精确的读法。
