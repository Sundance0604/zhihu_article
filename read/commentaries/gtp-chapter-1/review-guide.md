# 第一章复习提纲与答案要点

[返回阅读目录](README.md)。这份提纲用来在读完注疏后复述，不代替原文句读。可以先遮住答案，回答左侧问题，再用右侧核对。

## 一、波函数与谐振子：先把概率和状态讲清楚

| 自测问题 | 答案要点 |
|---|---|
| 波函数是一个粒子的位置吗？ | 不是一个确定位置数。它给每个位置安排一个复振幅，用来计算探测概率。 |
| 为什么不能提前只留下概率？ | 振幅相加会用到正负或箭头方向；先平方会把这些信息丢掉。$1/2+1/2$ 与 $1/2-1/2$ 就给不同答案。 |
| 相位是什么？ | 复平面箭头的角度。相位差是两根箭头方向差多少，影响合箭头长度。 |
| Born 规则实际怎么用？ | 离散结果振幅 $u+iv$ 对应概率 $u^2+v^2$；位置连续时，对区间积分 $\lvert\psi\rvert^2$。 |
| 向右平移为什么是 $\psi(x-a)$？ | 原峰值在 0，要使新峰值在 $a$，代入函数的自变量必须仍为 0。 |
| 动量中的导数从哪来？ | 小平移改变函数可用一阶导数表达；比较平移函数与算符指数的展开，得到 $-i\hbar\partial_x$。 |
| 定态为什么还带时间因子？ | 因子一直转，但长度为 1；位置概率分布不变，不等于小球静止。 |
| 为什么经常研究谐振子？ | 稳定最低点附近，势能首先保留二次项；许多系统的小振动近似相同。 |
| 零点能为什么不是零？ | 把位置压到一点会扩大动量成分与动能代价，最低总能量是两者平衡。 |
| $a^\dagger$ 在单粒子振子里产生什么？ | 一个振动激发，能量增加 $\hbar\omega$，不必理解成又制造一颗被困粒子。 |

复算两道题：比较两路振幅 $1/2,1/2$ 与 $1/2,-1/2$ 的结果；用“若标签是 2.3，下降后会发生什么”说明整数谱。

## 二、路径积分与热统计：知道自己究竟在积分什么

| 自测问题 | 答案要点 |
|---|---|
| 传播核拿来做什么？ | 与初始波函数对起点积分，给出后来波函数。 |
| 插入中间位置是否表示实际测量？ | 否，只是完备关系改写；实际留下测量记录会改变问题。 |
| 为什么出现 $e^{iS/\hbar}$？ | 每小段动量积分产生短时作用量，连乘使这些作用量相加。 |
| 为什么能叫“对路径求和”？ | 每组中间位置对应一条折线，多重积分遍历这些位置；连续符号是相应极限的简写。 |
| 经典轨迹怎样重新出现？ | 驻点附近相位一阶变化慢，邻近贡献较容易保留；许多非驻点贡献相互抵消。 |
| Wick 旋转改了什么？ | 把转动因子 $e^{-iEt/\hbar}$ 换成衰减 $e^{-E\tau/\hbar}$，不是改变实验时钟。 |
| 配分函数首先有什么用？ | 把全部热权重相加，作为分母使各状态概率总和为 1。 |
| 取迹为什么产生闭合路径？ | 迹加的是同一起点、终点标签的对角元素，再对公共端点积分。 |
| 编时为什么晚的写左边？ | 算符从右向左作用，较早的先执行。 |
| 源导数为什么能插入位置？ | 指数中的 $J(t)$ 正乘着 $x(t)$；对某处 $J$ 求导就取出该位置量。 |
| 谐振子为何只需二次涨落？ | 一次项因经典方程消失，三次以上项原本就没有。 |
| 行列式从哪来？ | 对每个独立模式做 Gaussian，各特征值因子相乘。 |

复算三步：完成动量平方；验证 $x=x_c+y$ 的一次项消失；由能谱作几何级数求振子 $Z$。

## 三、费米子：每个负号都要能指出从哪里来的

| 自测问题 | 答案要点 |
|---|---|
| 单模式为什么只有 0、1？ | 反对易关系推出 $N^2=N$。 |
| Grassmann 变量是不是很小的实数？ | 不是。它属于新代数，平方严格为零，不是忽略小量。 |
| 两变量函数为什么只有四项？ | 每个生成元最多出现一次，顺序可统一，基是 $1,\theta_1,\theta_2,\theta_1\theta_2$。 |
| 左导数的负号怎样检查？ | 先把待取变量移到左侧；$\partial_2(\theta_1\theta_2)=-\theta_1$。 |
| Berezin 积分是什么？ | 规定顺序下提取最高次系数，不是计算普通面积。 |
| 换元为什么有逆行列式？ | 最高次单项式乘了行列式，提取操作须乘倒数，保持积分定义。 |
| 双组奇 Gaussian 为什么给 det？ | 最高次项从每行每列选一个矩阵元，重排负号形成行列式。 |
| Pfaffian 记录什么？ | 一组变量里所有两两配对的带符号总和。 |
| 相干态在这里解决什么？ | 把算符矩阵元写成奇变量表达，并给出可插入时间片的完备关系。 |
| 反周期从哪来？ | 普通迹的相干态公式含 $\langle-\theta\rvert$；不带负号连恒等算符的迹都算不对。 |
| 半整数频率从哪来？ | 要求 $e^{i\nu\beta}=-1$，所以 $\nu=(2n+1)\pi/\beta$。 |

复算三个小例子：一个变量对的 Gaussian；两次左导数换序；用 $O=I$ 检查迹公式必须有负标签。

## 四、场论：从许多个坐标走到整个空间

| 自测问题 | 答案要点 |
|---|---|
| 场与单粒子波函数有什么不同？ | 场给空间每处一个动力学坐标；量子态需要给整个配置安排振幅。 |
| 自由场为什么是许多振子？ | Fourier 模式在二次模型里独立，每个满足振子方程。 |
| 为什么有相互作用？ | 非二次项在模式展开后把不同模式耦合，不再可逐个独立计算。 |
| 传播子为什么还要边界处方？ | 同一线性微分表达式有不同 Green 核，边界决定算哪种响应或关联。 |
| 真空为什么有涨落？ | 每个模式的基态不能同时把坐标、动量都固定为零。 |
| $\log Z$ 做什么？ | 从关联中去掉能分成独立组块的部分。 |
| 有效作用量为什么用 Legendre 变换？ | 从以外源为自变量，换到以平均响应为自变量组织量子修正。 |
| Dirac 场为什么需要矩阵？ | 一阶相对论方程需用矩阵消去交叉项，同时承载旋量分量结构。 |

复习重点是上述问题的物理用途。完整散射计算、一般正则化和旋量表示可在之后系统补学，不用靠记名字假装已懂。

## 五、规范、单极子与瞬子：从局部算到全球一致

| 自测问题 | 答案要点 |
|---|---|
| 势不同为什么场可以相同？ | 规范变化加上的梯度在相应电磁组合中抵消。 |
| 局部相位为什么需要协变导数？ | 普通导数多算了基准随位置变化的一项，规范势负责补偿。 |
| 非阿贝尔场强为什么有交换子？ | 不同内部搬运不交换，闭小回路比较会留下顺序差别。 |
| Higgs 质量项从哪来？ | 标量有非零最低半径时，协变导数展开出现 $A^2$ 的二次项。 |
| 为什么质量不是摩擦？ | 质量限制能量与动量关系，不表示真空里持续损失速度。 |
| 非零磁通为什么妨碍全球光滑势？ | 若 $F=dA$ 全球成立，闭球面 Stokes 积分应为零，与非零通量矛盾。 |
| 两片怎样保留非零通量？ | 赤道边界方向相反，但用的势不同，留下两势差的环量。 |
| 电荷量子化的整数从哪来？ | 过渡相位绕一圈必须回原值，总相位变化须为 $2\pi n$。 |
| 瞬子为什么要看无穷远？ | 整个四维积分需有限，渐近纯规范又保存一个全局映射类别。 |
| 自对偶为什么解 Yang–Mills？ | 把 $F=\pm*F$ 代入，Bianchi 恒等式直接给场方程。 |
| 作用量下界为什么与拓扑有关？ | 展开非负平方，余项是固定整数 $Q$ 的曲率积分。 |
| Derrick 论证为什么不是一维存在性证明？ | 缩放驻定是必要条件；未排除一种配置，不等于已证明它存在。 |

最值得合上书复述的一条路线：

**非零磁通 → 全球单势不可能 → 局部势拼接 → 波函数相位拼接 → 绕圈单值 → 整数条件。**

这条路线如果能讲明白，你已经看见为什么作者后面需要几何与拓扑；不必先背“物理中经常出现纤维丛”这类空泛概括。
