# 第二章复习：先解释，再核对答案

[阅读目录](README.md) · [完整合订本](chapter-2-commentary.md)

以下是新增复习题，不冒充原书题目。先遮住答案，能给出对象、条件与例子就可以继续。

| 问题 | 答案要点与回查 |
|---|---|
| 为什么角度代表元不能只当普通半开区间？ | 接缝两侧的邻近关系不同；需商拓扑。[前置补充](00-before-tensors.md) |
| 无头尾杆的取向为什么是 $\mathbb{RP}^2$？ | 固定中心与长度后，单位向量 $n,-n$ 不可区分；半球边界仍须粘合。[前置补充](00-before-tensors.md) |
| 配对与内积区别在哪？ | 前者输入余向量与向量；后者需额外的度量，把两个向量配成数。[前置补充](00-before-tensors.md) |
| 对偶映射为什么反向？ | $F^*\beta=\beta\circ F$，目标空间的读数被拉回原空间。[前置补充](00-before-tensors.md) |
| 为什么双线性型的对角值可以是二次函数？ | 两个槽分别线性，一起缩放产生平方。[张量](01-2.2.5.md) |
| 一个向量怎么接受余向量输入？ | $v$ 定义 $\alpha\mapsto\alpha(v)$，用到自然的双对偶识别，不需度量。[张量](01-2.2.5.md) |
| 任意张量都能写成一个简单张量吗？ | 不能；一般是简单张量的线性组合，可用秩为 2 的双线性型反例。[张量](01-2.2.5.md) |
| 缩并为什么需选一上一下两个槽？ | 使用向量与余向量的自然配对；换基矩阵抵消，迹为最小例子。[张量](01-2.2.5.md) |
| 为什么只要求有限交开？ | 无穷收缩区间交成单点，通常不开；强加任意交会改变通常拓扑。[拓扑](02-2.3.1.md) |
| 连续为什么用开集逆像？ | 等价于度量空间的逐点 ε–δ 条件，正像开是另一条件。[连续](03-2.3.2.md) |
| 邻域必须开吗？ | 不必，只需包含该点的一个开邻域。[Hausdorff](04-2.3.3.md) |
| 边界公式怎么写？ | $\partial A=\overline A\setminus A^\circ$，环境空间必须给定。[闭集](05-2.3.4.md) |
| 紧致就是闭有界吗？ | 只在欧氏空间等适用情形可这样判定，一般定义为任意开覆盖有有限子覆盖。[紧致](06-2.3.5.md) |
| 周期盒子的模式为什么离散？ | $e^{ikL}=1$，故 $k=2\pi n/L$；离散谱依赖具体算符和边界条件。[紧致](06-2.3.5.md) |
| 添一个无穷远点还缺什么？ | 邻域定义及场能否连续延伸的条件。[紧致](06-2.3.5.md) |
| 圆上两点能连起来，为什么仍非单连通？ | 道路连接不等于所有环路可缩。[连通](07-2.3.6.md) |
| 连续双射为什么可能不是同胚？ | 逆映射可能在接缝不连续，半开区间到圆是反例。[同胚](08-2.4.1.md) |
| 两环同胚为什么还可能解不开？ | 抽象同胚忘掉了三维环境中的嵌入关系。[同胚](08-2.4.1.md) |
| 同伦等价能保留紧致性吗？ | 不能，一点与开区间同伦等价；它保留另一类更粗的信息。[同伦型](10-2.4.3.md) |
| 为什么环面是 $\chi=0$？ | 胞腔计数一个顶点、两条边、一个面。[Euler](11-2.4.4.md) |
| 为什么连通和减 2？ | 三角孔连接：顶点不变，边加 3，面净加 1。[Euler](11-2.4.4.md) |
| 怎样从 Euler 公式限制正多面体？ | $pF=2E,qV=2E,V-E+F=2$，推出 $1/p+1/q>1/2$。[章末题](12-Problems.md) |

## 进入第三章前至少完整做这三件事

1. 给一个非标准基，验证向量—余向量配对不变，算一次 $(1,1)$ 张量的缩并。
2. 写出一个连续双射但非同胚的例子，以及一个不同胚却同伦等价的例子。
3. 分别计算三角形边框、填满三角形、球面与环面的 $\chi$，说明哪一个用了粘合后的计数。

这三项对应下一章需要的类型检查、空间比较与边界计数。物理模型暂时读懂用途即可，不作为掌握全部量子统计的要求。
