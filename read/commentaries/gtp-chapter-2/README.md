## 怎样使用

先读各节“这段在干什么”和具体例子，再看定义及推导。熟悉的分析基础只核对适用条件；张量、同胚、同伦等新构造则补定义、算例和关键证明。

原书确实省略的一般证明会明确标出，不用几个例子冒充完整证明。补充的动能、位移读数、边界条件等物理例子是解释用途，不把它们说成从纯数学定义必然推出的物理规律。
