# 第三章术语表：先认对象，再认名字

[阅读目录](README.md) · [核心定义](07-3.3.2.md)

| 术语 | 符号 | 到底是什么 | 不要混同 |
|---|---|---|---|
| 单纯形 simplex | $\sigma^r$ | $r+1$ 个仿射无关顶点的凸包 | 只有边框的多边形 |
| 面 face | $\tau\le\sigma$ | 由部分顶点构成的单纯形 | 只把二维部分叫面 |
| 单纯复形 simplicial complex | $K$ | 满足面封闭、共同面交集规则的积木清单 | 任意有重叠的网格 |
| 几何实现 polyhedron | $|K|$ | 所有积木作为几何集合的并 | 清单 $K$ 本身 |
| 三角剖分 triangulation | $(K,f)$ | 几何实现到研究空间的同胚模型 | 不经验证的图画 |
| 定向 orientation | 正负方向 | 顶点排序按偶、奇排列区分 | 必须先有空间外部法向量 |
| 链 chain | $c\in C_r$ | 有向 $r$ 维积木的整数形式组合 | 必须相连且有先后顺序的路径 |
| 边界算符 boundary operator | $\partial_r$ | 从 $r$ 链到 $r-1$ 链的同态 | 第二章的集合边界 |
| 链复形 chain complex | $C_\bullet$ | 相邻映射复合为零的一串群 | 必须处处正合的列 |
| 闭链 cycle | $Z_r=\ker\partial_r$ | 自己的代数边界为零的链 | 必须是一条单独的圆 |
| 边界链 boundary | $B_r=\operatorname{im}\partial_{r+1}$ | 某个高一维链的边界 | 任何拓扑边缘都自动是整数边界链 |
| 同调类 homology class | $[z]$ | 闭链模掉边界后的等价类 | 原空间中的点或同伦类 |
| 同调群 homology group | $H_r=Z_r/B_r$ | 所有同调类构成的阿贝尔群 | 全部闭链，或一般非交换基本群 |
| 挠元 torsion element | $n[z]=0$ | 非零但有限倍归零的类 | 画面上任何扭转都必产生的量 |
| Betti 数 | $b_r$ | 实系数同调的维数／整数自由秩 | 挠群元素个数或所有生成元数 |
| Euler 示性数 | $\chi$ | 单纯形个数或 Betti 数的交错和 | 空间的完整分类 |

这里多数名称不是额外增加对象，而是按角色区分：同一条链可能既是闭链又是边界链；同一条非零闭链也可能在商群中代表零类。判断时先问它属于哪个群、等式发生在哪一层。
