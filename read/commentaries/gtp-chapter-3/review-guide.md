# 第三章复习问题与答案要点

[阅读目录](README.md) · [合订本](chapter-3-commentary.md) · [术语表](glossary.md)

先遮住答案，用一个具体链说明。以下为新增复习题；原书 Exercise 3.1–3.3 与章末 Problems 3.1–3.2 的推导分别放在对应分册。

| 问题 | 答案要点与回查 |
|---|---|
| 商掉子群是删除那些元素吗？ | 不是，差在子群内的元素视为同类，整个子群成为零类。[群论用途](01-3.1.1.md) |
| $2\mathbb Z\cong\mathbb Z$，为什么商不为零？ | 同构没记录嵌入位置，实际子群不相等。[自由群](02-3.1.2.md) |
| 实数消元为何可能丢信息？ | 除以 2 改变整数格，实秩不记录关系系数的有限指数。[循环群](03-3.1.3.md) |
| 三个点必定生成二维单纯形吗？ | 必须仿射无关；共线只能生成低维集合。[单纯形](04-3.2.1.md) |
| 一块三角形与三角形的三条边有什么区别？ | 是否包括二维内部决定是否有一个二维单纯形。[单纯形](04-3.2.1.md) |
| 有限复形为什么仍有无限多个点？ | 有限是积木数；$|K|$ 是积木中所有点的空间。[复形](05-3.2.2.md) |
| 同一条边的正反方向要登记两个基吗？ | 不要；反向就是同一生成元的负号。[定向](06-3.3.1.md) |
| 为什么 $\partial[A,B]=B-A$？ | 相接边的内部顶点须抵消。[链与边界](07-3.3.2.md) |
| $\partial^2=0$ 的一般证明是什么？ | 每删两个顶点得到同一面两次，次序造成相反符号。[链与边界](07-3.3.2.md) |
| 闭链与边界链怎样区分？ | 一个是检验自己边界为零，一个是寻找高维前像。[链与边界](07-3.3.2.md) |
| 为什么像包含于核？ | $b=\partial d$ 则 $\partial b=\partial^2d=0$。[链与边界](07-3.3.2.md) |
| 链复形必须处处正合吗？ | 不必须，同调恰好测量像未填满核的部分。[链与边界](07-3.3.2.md) |
| 实心三角形为何有 $H_1=0$？ | 一维闭链群没有消失，只是它全成为二维链的边界。[同调例子](08-3.3.3.md) |
| 球面为何有 $H_2=\mathbb Z$？ | 面片可一致组成二维闭链，研究空间内没有三维填充物。[同调例子](08-3.3.3.md) |
| 连通空间的 $H_0$ 为什么不为零？ | 顶点之差是边界，单个顶点总系数为 1 不是边界。[H0](09-3.3.4.md) |
| Möbius 带的边缘为何不使 $2[z]=0$？ | 几何边界不自动是整体整数链边界；其边缘类是非零 $2[z]$。[Möbius 带](10-3.3.5.md#mobius) |
| 证明 $2[z]=0$ 后还缺什么？ | 要证明 $[z]\ne0$，且全部类由它生成。[射影平面](10-3.3.5.md#projective-plane) |
| 环面与 Klein 瓶的差别在哪里？ | 精简胞腔边界分别为 $0$ 与 $2a$。[曲面](10-3.3.5.md) |
| 两个不交圆的 H0 是什么？ | $\mathbb Z^2$；与两个圆在一点相粘不同。[连通分支](11-3.4.1.md) |
| 不可定向一定使 H1 有挠吗？ | 不一定，Möbius 带无挠。[结构](12-3.4.2.md) |
| 模 2 系数会不会反映二阶现象？ | 会，但不能完整恢复整数挠；射影平面模 2 有非零 H2。[系数选择](12-3.4.2.md) |
| Euler 证明中什么项抵消？ | 每个边界空间维数在相邻维度以相反符号出现。[Betti 与 Euler](13-3.4.3.md) |
| 一个边界孔必添一个独立圈吗？ | 否，q 个边界类总和为零，独立贡献 q−1 个。[章末题](14-Problems.md) |
| crosscap 的 q 个二倍关系独立吗？ | 标准单面模型只有一条关系 $2(a_1+\cdots+a_q)=0$。[章末题](14-Problems.md) |

## 至少独立完成的三个模型

1. 固定三角形的顶点、边与面基，写出 $D_1,D_2$，验算 $D_1D_2=0$；删掉面后比较 $H_1$。
2. 按原图十个面，通过星形树坐标消去射影平面关系，说明最后确实只剩一个二阶生成元。
3. 从 $I_r=b_r+\beta_r+\beta_{r-1}$ 独立推出 Euler–Poincaré 等式，说明为什么需要使用实系数维数或等价的自由秩。

群论熟悉部分通过诊断即可。新重点是构造如何成立、填充物必须属于哪个空间，以及使用什么系数，不是把所有曲面同调表背下来。
