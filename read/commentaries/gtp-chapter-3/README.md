## 怎么读

每节先说“这段在干什么”，再从具体模型解释定义，并把关键计算展开。你熟悉的代数不必逐行重学，但应检查群与向量空间、整数与实数系数、同构与实际包含关系的区别。

建议完整算通三角形边框与实心三角形，再读球面，然后读 Möbius 带与射影平面。第一次看见 $\mathbb Z_2$ 时，重点不是背空间名称，而是说明为什么类非零、两倍却为零。

## 原页、校记与验证

[原页索引](source-pages.md) · [来源与页图哈希](source-manifest.json) · [精确计算脚本](verify-homology.py) · [计算结果](verification-results.json)。

原图是完整页，跨小节页面不裁断，分册标出本节位置；同一页可能出现在相邻分册。页序为印刷页加 23。文件提取文本用于检索，公式和图示结合页图核对；中文讲解是新增注疏，不是英文转录，也不改动影印。

对同调拓扑不变性、同伦不变性、Smith 标准形和胞腔同调等一般定理，说明实际依赖，不以少量算例冒充全证。环面等例子的胞腔路线是明确标出的补充方法；它与严格单纯复形不同。

独立核验使用原书三角面列表生成整数边界矩阵，以精确运算检查 8 个模型；计算只是算术核验，不替代一般定理证明。需要复算时，在本目录运行 `python verify-homology.py`，只使用 Python 标准库，更新旁边的结果 JSON。
