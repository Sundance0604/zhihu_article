# 二十世纪和声第一章章句集注

底本：Vincent Persichetti，*Twentieth-Century Harmony: Creative Aspects and Practice*，Chapter 1，Intervals。采用本项目所存英文扫描本，覆盖印刷页 **13–30**，对应 PDF 阅读器第 **11–28** 页。包含五节正文、Source Material、Applications 全部 12 题，以及 Ex. 1-1 至 Ex. 1-26。

本章要学的是：怎样用音程关系、实际排列、音区和音色，主动组织一段音乐的张力。你已有的古典和声知识依然有用；这里会增加一组分析与写作时可以独立控制的因素。

## 注疏的组织方式

每页先放完整原页影印，随后按该页论述次序解释。谱例、排版和英文原句以影印为准；中文采用短引定位、释义、具体算例和创作解释，不把扫描识别结果当作校定原文。同页跨小节时，两个分册可以重复显示整页，各自只注释属于自己的段落。

“句读”解释作者这句话正在解决什么问题。“疏”补出略去的知识、计算和比较步骤。“集注”把原书、你的旧课和实际写作联系起来。“校读”区分原书的创作概括、当前采用的约定与不能直接推广的判断。补充例子均明确标为“自拟”，不冒充原书谱例。

知识对照使用三个标记：**【已有】**表示现存笔记有明确对应；**【深化】**表示名称已经见过，本章增加新的问题和操作；**【重点新增】**表示现存笔记文字及已整理的课程索引未见相应系统讲解。它们描述材料覆盖，不评判你的掌握程度，也不声称讲师整套课程从未讲过。

课程基线为 `composition-studies/sources/harmony-counterpoint` 下的三份整理，以及本项目的 H&C 笔记。后一份增加了 Lesson 27；早期索引止于 Lesson 26，故不能只据旧索引确定你的接触范围。原笔记中的小调名称、数字低音基准等问题沿用独立勘误的修正，不带进新注疏。

## 本章读法

每次读完一小段，至少做一次比较：保持音名相同而改音区，保持节奏力度相同而改音程，或者保持和弦相同而改发音。先预测变化，再听，再解释哪些因素可能造成差别。原书把技术放在创作情境中，单独背分类表不能代替这一步。

正文的 C4 表示中央 C；八度号只用于说明实际音区。没有写八度号的 C、E、G 主要表示音名或和弦成员。P、M、m、A、d 分别表示纯、大、小、增、减；它们不会被罗马数字的大小写替代。所有“较紧张”“较柔和”都应连同具体配置理解。

配套听觉例子是自拟的合成音比较材料，供核对音高、间距和张力布局；乐器音色仍须结合原谱与真实演奏理解。请将整个文件夹一起保存，`assets` 是原页图片，`listening` 是听觉材料；合订本和分册共用这些文件。
