# 第一章听觉比较

[返回阅读目录](../README.md)

这些是本注自拟、用简单谐波合成音制作的比较材料，不是原书谱例录音，也不模拟长笛、弱音弦乐或管弦乐。它们用于听清音高、间距、分组与动态条件；配器结论仍要结合真实乐器。

先以舒适音量播放。低音的呈现受耳机、音箱和房间影响，听不清低区并不能证明某种配置本身无效。各例未做主观等响度校准，不宜据音量差给音程作科学排名。

## 一 十二种八度内距离

[播放固定低音的十二种距离](01-interval-palette.wav)

低音始终为 C4，上音依次 Db4、D4、Eb4、E4、F4、F#4、G4、Ab4、A4、Bb4、B4、C5，每组约1.3秒，中间留短停顿。先按六类术语描述，再记录同类内部的差别。对应 [构成与语境](../01-construction.md)。

## 二 同一个纯四度的两个上下文

[播放两种四度语境](02-fourth-context.wav)

前半是 C4–E4 → C4–F4 → C4–E4；后半是 C4–Db4 → C4–Eb4 → C4–F4。听第二个和最后一个 C–F：它们的距离相同，在短过程中的角色可能不同。这是极简示范，还没有完整乐句的全部条件。对应原书 Ex. 1-3 的讨论，自拟材料不替代原例。

## 三 小二度 转位与扩展

[播放小二度 大七度 小九度](03-inversion-and-extension.wav)

依次 C4–Db4、Db4–C5、C4–Db5。第一到第二是转位，第一到第三是扩成复音程。记录“近距咬合”“接近八度的紧张”“宽距中的关系”各有什么不同。对应 [转位与间距](../02-inversion-spacing.md)。

## 四 整体改变音区

[播放三个音区的同一配置](04-register.wav)

依次 C2–E2–G2、C3–E3–G3、C4–E4–G4。每组相邻距离相同，仅整体音区变动。请与上一例区别：这不是音程转位。

## 五 相同音级材料的两种排列

[播放低处密集与拉开配置](05-spacing.wav)

依次 C2–E2–G2–B2 与 C2–G2–E3–B3。音级材料相同，实际间距、上部音区和重心不同。它展示综合配置变化，不能把结果只归于某一个音的移动。对应 [和弦内部关系](../03-intervals-in-chords.md) 与 [泛音](../04-overtones.md)。

## 六 张力与力度的相反过程

[播放自拟的两条相反过程](06-tension-and-dynamics.wav)

前半低音为 C4，上音依次 G4、E4、D4、B4、Db4，音量逐步下降；后半倒转音程序列，同时音量逐步增加。它按开放、柔和、温和、尖锐等差别作创作示意；并非声称五个音程有严格普遍的线性排名。

先听是否能察觉材料变化，再对照 [实践题5](../07-applications.md)。如果最终小二度太轻而不突出，想想你可以怎样改变时值、音区或节奏，同时保留力度方向。

## 七 平均律与5比4大三度

[播放两种大三度交替](07-temperament.wav)

固定 C4，依次是平均律 E4、C4频率的5/4，再重复一次。理想谐波合成让某些分音之间的拍动较容易观察。差别不仅取决于音程比，也取决于本例选用的分音强度；它不代表所有真实乐器上差别一样明显。

对应 [泛音与音分计算](../04-overtones.md)。不要把“纯比大三度”与“所有条件下艺术效果更好”画等号。

## 八 团块与两个三度对

[播放同时音组与分组后的材料](08-grouping.wav)

先同时发出 C4–D4–E4–F#4，再交替 C4–E4 与 D4–F#4。后半改变了同时发声关系和时序，因此是织体变化的演示，不是证明仅仅换乐器便产生同样结果。

对应原书 Ex. 1-20 和 Medium 的分组讨论。

## 九 相同音程的持续与衰减

[播放持续与衰减的小二度](09-sustain-and-decay.wav)

两次都是 C4–Db4，先较均匀持续，后较快衰减。它仅改变简化发音包络，不代表真实钢琴与弦乐的完整音色。听音程摩擦在时间中的显露方式，联系 [媒介与和声](../05-medium.md)。

## 怎样记录听觉

每例写三句话即可：我原先预期什么；实际听到什么；下一次应保持哪些条件、只改哪一项来继续比较。不要为了符合教材形容词而忽略自己的听感；先核对音高、音区与设备条件，再回到完整乐句。
