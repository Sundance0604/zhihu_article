# 术语和校读说明

[阅读目录](README.md)

这里整理正文中容易误读的地方。它不是出版社官方勘误，也不依据后来的理论替换原书；原页始终保留。学习时应区分原书的创作经验、术语约定、算术事实与本注新增解释。

## 一 主要术语

| 英文 | 本注用语 | 使用时的要点 |
|---|---|---|
| construction | 构成、构造 | 既包括音程材料分类，也为和弦构造作准备 |
| consonance / dissonance | 协和 / 不协和 | 有时谈声响性质，有时谈语境中的稳定程度 |
| open consonance | 开放协和 | 五度、八度的类别；不等同于开放排列 |
| soft consonance | 柔和协和 | 三度、六度；不表示必须弱奏 |
| sharp dissonance | 尖锐不协和 | 小二、大七；sharp 不是升号 |
| mild dissonance | 温和不协和 | 大二、小七；mild 不表示小音程 |
| ambiguous | 模棱两可 | 不能只凭名称确定角色 |
| neutral | 中性 | 常指不被听成强烈要求特定解决，不能等同无色彩 |
| restless | 不安、倾向继续 | 与声音粗糙程度不是同一指标 |
| spacing | 间距、配置 | 要看实际音区与相邻空隙 |
| register | 音区 | 相同名称的音程放在哪个高低范围 |
| medium | 发声媒介 | 乐器、人声、编制与相关演奏条件 |
| partial | 分音 | 包括第一分音即基音；不保证所有分音均为整数倍 |
| overtone | 泛音 | 通常指基音以上分音；原书有时较宽松使用 |
| harmonic | 谐波；弦乐泛音奏法 | 声学与演奏法两个用法需看上下文 |
| doubling / tripling | 倍增 / 三重化 | 可改重量、音色、层次，不必增加新音级 |
| coupled writing | 成组配对或加倍的写作 | 依具体谱例判断是否同音、八度或固定音程配对 |
| strand | 一条可追踪的线或层 | 可以是一条单线，也可以是成组音程 |
| red. | 缩编谱 | 页码只适用于作者指明的版本 |
| application | 实践题、应用 | 不是要求找出唯一和弦答案 |

## 二 原书主要概括的适用范围

| 位置 | 原书论述 | 本注怎样处理 |
|---|---|---|
| p13 | 任何音可连接任何音 | 材料允许范围扩大；效果仍依上下文、形式和具体写作 |
| pp13–14 | 物理性质与基本音程质量 | 固定声音可作物理比较；名称相同而音色、音区、调律改变时，声音条件已不同 |
| p14 | 六组音程分类 | 作为起步比较，不是跨风格、音区与媒介的永久总排名 |
| p15 | 四度随协和/不协和环境改变 | 连同具体低音、线条、时值和上下文理解 |
| pp15、18、21 | 三全音可中性、可不安；含三全音和弦倾向不安 | “倾向”与语境限制并用，不将任一句孤立提升为绝对规则 |
| p17 | 五度转位成为不稳定四度 | 结合前节四度讨论；不推成所有四度恒定不稳定 |
| pp17–18 | 展开后更丰富、更明亮、更少咬合 | 属经验性声响描述，不等同固定声压或严格张力数值 |
| p20 | 多音和弦的音程计数 | n(n−1)/2 是配对数量；要区分实际声部对与合并八度后的音级对 |
| p21 | 四度的角色由其他关系决定 | 特别适合核对给出的三音配置；复杂音组仍检查完整关系 |
| pp22–25 | 低宽高密较清晰或共鸣较好 | 对特定目标有用；作者同时保留浑浊和声的创作价值 |
| p23 | 任何音都生成泛音列 | 作为理想谐波声模型；纯音、非谐和分音与真实偏差另需说明 |
| p24 | 高次分音与平均律不重合 | 用频率比和音分核对；低次也可能有小偏差 |
| p24 | 第六分音以后听觉判断的强措辞 | 不作为人耳能力的硬边界；保留其反对机械推导和弦的论点 |
| p24 | 五度因分音更低而更有力量 | 属构造与共鸣思路；实际能量取决于各分音振幅、乐器和发音 |
| pp25–27 | 音色改变和声性质 | 结合音区、动态、时值和配器说明，避免单一原因解释 |

## 三 对照旧笔记时采用的修正

这些问题在 `composition-studies` 的独立勘误已有记录。本注沿用修正，不改写你的旧笔记，也不据笔记措辞推定讲师原话。

1. **小调名称：**自然小调升第七级形成和声小调；传统旋律小调通常上行升第六、第七级，下行回自然小调。原笔记 L3 两名称曾颠倒。
2. **数字低音基准：**从实际低音往上数距离，再结合调号、临时记号；不是从主音数第六级、第三级。正文中新写作例同样遵守这个区分。
3. **复音程：**跨一个八度时泛音程度数加七；跨多个八度要逐次处理，性质和半音数另算。
4. **终止分类：**只有处在相应正格终止语境，才比较 PAC 与 IAC；不是任意不满足 PAC 的结尾都叫 IAC。
5. **持续低音：**低音不动并不能单独证明和声不变，也不能单独证明上方音全是装饰。
6. **终止四六：**典型外音解释主要涉及调性 1、3 向 7、2；调性 5 本身就是属根音，不能把全部上方音一概称为外音。
7. **属低音上的 8–7：**在 C 大调以 G 为低音时，是上方 G→F，即调性 5→4，不是主音八度下行。

正文有时采用“相对于自然小调升 7”之类写法，是为说明变化基准，不把升降记号自动混成绝对键盘音名。

## 四 新增算例的约定

所有未注明调律的音高表按十二平均律识别半音距离，C4 为中央 C。泛音一节的整数比则是理想谐波模型，转换为音分时使用 1200 log₂(r)。两种模型之间的差异正是讲解对象，不静默混用。

对复音程可以同时记“实际大九度”和“由大二度扩展的关系”。若讨论音级类别，需要说明已作八度归约；若讨论清晰度、声部位置和发音，仍回到实际距离。

原书谱例的乐器、动态、连线、临时记号和八度以影印为准。本注的自拟短例与合成音，均不用于替换原书旋律或宣称已认证原谱全部演奏细节。
