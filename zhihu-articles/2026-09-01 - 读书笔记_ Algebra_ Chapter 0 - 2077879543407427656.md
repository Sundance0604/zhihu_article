## Preliminaries: Set theory and categories

### Function between sets

Second view of bijections: if $f:A\to B$ is a bijection, then can define a function $g:B\to A$ . $g$ indicates that $g\circ f=\text{id}_A$ . Left inverse $iff$ injective, right inverse $iff$ surjective.

**monomorphism: **monomorphism $iff$ injective: $\forall Z;\alpha',\alpha'':Z\to A$ , $f\circ \alpha'=f \circ \alpha''\Rightarrow \alpha'=\alpha''$ . Surjective is epimorphism.

**canonical decomposition: **Let $f:A\to B$ be a function. Define an equivalence relation on $A$ by $a\sim a'\iff f(a)=f(a')$. The canonical decomposition of $f$ is

$ A\twoheadrightarrow A/{\sim}\xrightarrow{\cong}\operatorname{im}f\hookrightarrow B, $

or equivalently,

$ f=\iota\circ\bar f\circ\pi. $

Here the map is decomposed into a **surjection**, then a **bijection**, then an **injection**.

The canonical projection $\pi:A\to A/{\sim}$ is defined by $\pi(a)=[a]$. It is surjective because every equivalence class is represented by some $a\in A$.

The induced map $\bar f:A/{\sim}\to\operatorname{im}f$ is defined by $\bar f([a])=f(a)$. This is well-defined because $[a]=[a']$ implies $a\sim a'$, hence $f(a)=f(a')$. It is bijective: equal outputs imply equal equivalence classes, and every element of $\operatorname{im}f$ is reached.

The inclusion map $\iota:\operatorname{im}f\hookrightarrow B$ is defined by $\iota(b)=b$. It simply regards an element of $\operatorname{im}f$ as an element of $B$, and is therefore injective.

Thus for every $a\in A$,

$ a\xmapsto{\pi}[a]\xmapsto{\bar f}f(a)\xmapsto{\iota}f(a), $

so $(\iota\circ\bar f\circ\pi)(a)=f(a)$, hence $f=\iota\circ\bar f\circ\pi$.

### Categories

A category C consists of a class $Obj(C)$ and $Hom_C(A,B)$ of morphisms, which have porperties of identity and composition.

### Morphisms

A morphism $f \in \operatorname{Hom}_{\mathcal{C}}(A,B)$ is an **isomorphism** if it has a (two-sided) inverse under composition: that is, if $\exists g \in \operatorname{Hom}_{\mathcal{C}}(B,A)$ such that

$ gf = 1_A,\qquad fg = 1_B. $

A category called groupoids if every morphism is inversible. The endomorphism is $f: A\to A$ , and automorphism is inversible endomorphism. $Aut_C(A)$ is a group. Monomorphism is injective while epimorphism is surjective. Monomorphism and epimorphism $\to$ isomorphism not hold for all categories.

### Universal properties

$I$ is initial: $\forall A\in Obj(C)$ , $Hom_C(I,A)$ is a singleton, having single element. $F$ is final respectively. Universal property defines an object by its relations to all other objects. For example, pair $(\pi, A/\text{~})$ is an initial object of this category, product owns terminal type universal property and coproduct(like disjoint) is an initial.

### Canonical decomposition and Lagrange’s theorem

Every group homomorphism $\varphi:G\to G'$ can be decomposed as $G\twoheadrightarrow G/\ker\varphi\xrightarrow{\sim}\operatorname{im}\varphi\hookrightarrow G'$, i.e., surjective–isomorphism–injective. If $\varphi$ is surjective, then $G'\cong G/\ker\varphi$.

The first step removes non-injectivity, since $\varphi(a)=\varphi(b)\iff a\ker\varphi=b\ker\varphi$. By the universal property, there exists a unique homomorphism $\widetilde\varphi:G/\ker\varphi\to\operatorname{im}\varphi$, defined by $\widetilde\varphi(g\ker\varphi)=\varphi(g)$.

Let $K=\ker\varphi$. It is injective since $\widetilde\varphi(aK)=\widetilde\varphi(bK)\Rightarrow\varphi(a)=\varphi(b)\Rightarrow aK=bK$, and surjective by the definition of $\operatorname{im}\varphi$. Hence $\widetilde\varphi$ is an isomorphism.

**Group Presentation**

A presentation of a group $G$ is an isomorphism $G\cong F(A)/R$, where $A$ is a set of generators and $R\trianglelefteq F(A)$ is the normal subgroup of relations. Equivalently, there exists a surjective homomorphism $\rho:F(A)\twoheadrightarrow G$ with $R=\ker\rho$.

**Correspondence Theorem**

$H\subseteq K\subseteq G$ , then $u: K\to K/H$ is bijective.

**Third Isomorphism Theorem**

Let $H\trianglelefteq G$, $N\trianglelefteq G$, and $H\subseteq N$. Since $\pi_N:G\to G/N$ satisfies $H\subseteq\ker\pi_N=N$, the universal property gives a unique homomorphism $\widetilde\pi:G/H\to G/N$, defined by $\widetilde\pi(gH)=gN$.

It is surjective, with $\ker\widetilde\pi=\{gH:g\in N\}=N/H$. Hence, by the first isomorphism theorem, $(G/H)/(N/H)\cong G/N$. Moreover, $N/H\trianglelefteq G/H\iff N\trianglelefteq G$.

**Second Isomorphism Theorem**

Let $H,K\le G$ with $H\trianglelefteq G$. Then $HK\le G$, $H\trianglelefteq HK$, and $HK/H\cong K/(H\cap K)$.

**Proof.** Consider $\pi:G\to G/H$. Since $\pi(K)\le G/H$, its preimage $\pi^{-1}(\pi(K))=KH=HK$ is a subgroup of $G$, where $KH=HK$ follows from normality of $H$. Also, $H\trianglelefteq HK$.

Define $\varphi:K\to HK/H$ by $\varphi(k)=Hk$, which is the composition $K\hookrightarrow HK\to HK/H$, hence a homomorphism. It is surjective since every coset $H(hk)=Hk=\varphi(k)$.

Moreover, $\ker\varphi=\{k\in K:Hk=H\}=H\cap K$. Thus $H\cap K\trianglelefteq K$, and by the First Isomorphism Theorem, $K/(H\cap K)\cong HK/H$.

**Lagrange's Theorem**

$[G:H]=|G/H|$

For $H\le G$, the index $[G:H]=|G/H|$ counts the distinct left cosets of $H$ in $G$. Each coset has the same size as $H$, since $f_g:H\to gH$, $h\mapsto gh$, is bijective. Distinct cosets are disjoint and partition $G$. Thus, for finite $G$, $|G|=[G:H]|H|$, implying $|H|\mid|G|$.

For a homomorphism $\varphi:G\to G'$ in $\mathbf{Ab}$, the cokernel is $\operatorname{coker}\varphi=G'/\operatorname{im}\varphi$. Its universal property states that if $\alpha:G'\to L$ satisfies $\alpha\circ\varphi=0$, equivalently $\operatorname{im}\varphi\subseteq\ker\alpha$, then $\alpha$ factors uniquely through $\operatorname{coker}\varphi$.

Thus $\operatorname{coker}\varphi=0\iff\varphi$ is surjective, equivalently an epimorphism in $\mathbf{Ab}$.

### Group actions

A group action corresponds to a homomorphism $\sigma:G\to\operatorname{Aut}_{\mathcal C}(A)$. For $\mathcal C=\mathbf{Set}$, $\operatorname{Aut}_{\mathbf{Set}}(A)=S_A$, the permutation group of $A$. The action is **faithful** iff $\sigma$ is injective.

Equivalently, an action is a map $\rho:G\times A\to A$, written $ga:=\rho(g,a)$, satisfying $e_Ga=a$ and $(gh)a=g(ha)$. An action is faithful iff only $e_G$ fixes every $a\in A$; it is **free** iff only $e_G$ fixes any given $a\in A$.

**Cayley’s Theorem**

Every group acts faithfully on its underlying set by left multiplication: $L_g:G\to G$, $L_g(x)=gx$. The homomorphism $\sigma:G\to S_G$, $g\mapsto L_g$, is injective, so $G\cong\operatorname{im}\sigma\le S_G$.

**Transitive Actions and the Category $G$-Set**

An action is **transitive** if $\forall a,b\in A,\ \exists g\in G:\ b=ga$. The **orbit** of $a$ is $O_G(a)=\{ga:g\in G\}$, and its **stabilizer** is $\operatorname{Stab}_G(a)=\{g\in G:ga=a\}$. Orbits partition $A$, and each orbit is a transitive $G$-set.

The category $G$-Set has objects $(\rho,A)$, where $\rho$ is a $G$-action, and morphisms $\varphi:A\to A'$ satisfying $\varphi(ga)=g\varphi(a)$ (equivariant maps). Isomorphisms in $G$-Set are precisely the equivariant bijections.

**Orbit-stabilizer theorem**

If $O$ is an orbit of the action of a finite group $G$ on a set $A$ , then $O$ is a finite set and $|O|$ divides $|G|$ .
